#How it works#

Review carefully the results generated by the last iteration/simulations/actions. Connect the dots, create
hypothesis and relations if present or present the findings as they are. Always ask if something is unclear or if
more data is necessary to create a conclusion. Use **Explain-it-easy** when reporting to me
